# Lavra — roteiro de implementação

**Spec:** `docs/superpowers/specs/2026-10-20-lavra-design.md`

O design cobre seis subsistemas. Cada plano abaixo gera software testável sozinho e vira **uma branch e um PR** para a `main`. Os planos 03 a 06 são escritos **depois** que os anteriores fecham, porque dependem do resultado do spike de conectividade (quais provedores funcionam do navegador) e da API final da biblioteca.

| # | Plano | Entrega verificável | Depende de |
|---|---|---|---|
| 01 | Fundação do repositório + spike de conectividade | monorepo, CI verde, governança (commits, PRs, issues, segurança), página de spike rodada pelo autor com chaves reais | — |
| 02 | Biblioteca `@lavra/pii-br` | detectar, mascarar, reidratar e validar saída, com corpus de testes | 01 |
| 03 | App: bancada + ata corporativa + provedores com fallback + revisão por seção | gerar uma ata corporativa de ponta a ponta na prévia HTML | 01, 02 |
| 04 | Exportação PDF/DOCX + logo + copiar tarefas por responsável | baixar PDF e DOCX da ata corporativa | 03 |
| 05 | Tipos formais: CIPA, condomínio, Ltda + `docs/base-legal.md` | os três tipos gerando e exportando | 04 |
| 06 | Modo exemplo, página "Privacidade: como verificar", README, deploy no GitHub Pages | demo pública + README com GIF | 05 |

## Fluxo de trabalho no repositório (vale para todos os planos)

- Branch por plano: `feat/01-fundacao`, `feat/02-pii-br`, … a partir da `main` atualizada.
- **Conventional Commits** com descrição em pt-BR acentuada (`feat(pii-br): adiciona detector de CNPJ alfanumérico`). Escopos: `pii-br`, `web`, `ci`, `docs`, `repo`.
- Mensagens de commit sempre por arquivo UTF-8 (`git commit -F`) para preservar acentos no Windows.
- PR com o template do repositório, título no formato Conventional Commits, **squash merge**. O título do PR vira o commit na `main`.
- Antes de cada commit e PR: `grep` por nomes de clientes/produtos de terceiros (lista na memória do projeto) — o repositório é público.
- Suíte de testes sempre com teto de workers; nunca duas suítes ao mesmo tempo.
