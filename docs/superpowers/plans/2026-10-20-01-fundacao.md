# Plano 01 — Fundação do repositório + spike de conectividade

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** monorepo pnpm com qualidade de vitrine (lint, typecheck, testes, CI, convenção de commits, governança, segurança da cadeia de dependências) e um esqueleto do app com CSP ativa; mais o spike que prova quais provedores de IA aceitam chamada direta do navegador.

**Architecture:** workspace pnpm com `apps/web` (Vite + React) e `packages/*`; configuração compartilhada na raiz (TS, ESLint, Prettier, Vitest com `projects`). Hooks locais com lefthook + commitlint; CI no GitHub Actions com actions fixadas por SHA; release e CHANGELOG por release-please a partir dos Conventional Commits.

**Tech Stack (versões verificadas em 20/10/2026):** Node 24 LTS (≥ 24.15.0) · pnpm 10 (última 10.x — Dependabot documenta suporte até a v10) · TypeScript **6.0.3** (o 7.0 quebra o typescript-eslint; tsconfig já no dialeto compatível com o 7) · Vite 8.3 · `@vitejs/plugin-react` 6.1 · React 19.3 · Vitest 5.0 + `@vitest/coverage-v8` · jsdom 30 · Testing Library (react 16.3, dom 10.4, jest-dom 7.0, user-event 14.6) · ESLint 10 + typescript-eslint 8 (type-checked) + `@eslint-react/eslint-plugin` 5 + `eslint-plugin-react-hooks` 7 · Prettier 3.9 · lefthook 2.2 · commitlint 21 · release-please-action v5 · actions: checkout v7, setup-node v7, pnpm/action-setup v6, scorecard-action v2, codeql-action v4.

**Spec:** `docs/superpowers/specs/2026-10-20-lavra-design.md` (seções 4, 5.1, 9, 11, 12)

**Branch/PR:** `feat/01-fundacao` → PR "chore(repo): fundação do monorepo, CI e governança".

## Global Constraints

- Repositório **público**: nenhum nome de cliente ou produto de terceiros em arquivos, commits, PRs ou issues.
- Conventional Commits, descrição em pt-BR acentuada, mensagem via arquivo UTF-8 (`git commit -F`). Sem linha `Co-Authored-By`.
- Texto visível ao usuário em pt-BR com acentuação correta.
- Nenhum script, fonte ou CSS de terceiros em tempo de execução.
- CSP em `<meta>` exatamente: `default-src 'self'; script-src 'self'; style-src 'self'; img-src 'self' data: blob:; font-src 'self'; connect-src https://api.openai.com https://generativelanguage.googleapis.com https://api.anthropic.com; object-src 'none'; base-uri 'self'; form-action 'none'`.
- Testes sempre com `--maxWorkers` (4 local, 2 no CI); nunca duas suítes ao mesmo tempo.
- Workflows: `permissions: read-all` (ou `contents: read`) no topo; escrita só no job que precisa; toda action de terceiro fixada por **SHA de commit** com comentário da tag.
- Chaves de API **nunca** em arquivos do repositório, logs ou chat.
- Copyright da licença: `Copyright (c) 2026 Diego Antunes`.

## Review Focus

1. **Build do Vite injetando script inline** (quebraria a CSP silenciosamente em produção): esperado `dist/index.html` sem `<script>` inline. Teste no Task 2 (`scripts/check-csp.mjs`).
2. **Asset pequeno virando `data:` em lugar não permitido** (fonte/script inline): esperado `assetsInlineLimit: 0`. Verificado no Task 2 pelo mesmo script (nenhum `src="data:` em `<script>`).
3. **Commit com mensagem fora do padrão passando pelo hook**: esperado bloqueio. Teste no Task 3.
4. **Dependabot com lockfile do pnpm quebrando o CI** (`--frozen-lockfile`): esperado CI verde no primeiro PR do Dependabot. Verificação no Task 7 (observar o primeiro PR).
5. **Provedor responde CORS mas recusa schema estruturado** (spike "funciona" só com texto livre): esperado o spike testar **JSON com schema**, não só "olá". Critério no Task 6.
